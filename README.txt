DG WORK MANAGER - MOBILE APP

QUICK START:
1. Put this folder on a web host that supports static HTML (for example, GitHub Pages, Netlify, Vercel, etc.).
2. Open the website URL on Boss's Android phone in Chrome.
3. Chrome menu -> Add to Home screen / Install app.
4. Add work from the app.
5. Data is saved in the browser's localStorage on that phone.

IMPORTANT:
- This version is designed for ONE PHONE / ONE USER.
- Data does NOT automatically sync between two phones.
- Do not clear Chrome site data or uninstall/reset the app without first using Settings -> Download Backup.
- To move data to another phone: Settings -> Download Backup on old phone, then open the app on the new phone -> Settings -> choose the JSON backup file.

FEATURES:
Dashboard, Add Work, Active Work, Due/Urgent view, Completed History, Payment/Outstanding count, Backup/Restore, offline cache/PWA.

RECOMMENDED:
Use the app mainly on Boss's phone. Keep the backup JSON in Google Drive/WhatsApp to yourself periodically.
